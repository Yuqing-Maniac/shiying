映刻录屏
========

一、启动和主题
  银河麒麟／Linux：完整解压后双击「映刻录屏」。如需添加或更新开始菜单和桌面入口，
  运行同目录的「安装到菜单.sh」。移动便携目录后，从新位置再运行一次此脚本。
  Windows：完整解压后双击「映刻录屏.exe」。可在设置中创建或更新桌面和开始菜单快捷方式。
  两个平台默认采用深色界面。点击主界面右上方的主题按钮可一键切换浅色或深色，下次启动会记住选择。
  开场对焦动效约 0.62 秒，显示期间可立即操作。

二、截图与录屏
  横条左侧是全屏截图、窗口截图、区域截图，右侧是全屏录屏、窗口录屏、区域录屏。
  选择范围后点「截图」或「录制」。多屏环境可指定显示器。
  窗口模式记录选中时的可见屏幕范围，窗口移动或被遮挡会影响结果。区域模式可拖选，
  右键或 Esc 取消。PNG 截图保留选区原始像素，可选显示缩略图。

三、设置
  可更换保存目录、倒计时、声音设备、指针显示和点击高亮，也可选择记住上次选区。
  录屏支持 H.264／H.265、MP4／MKV、原始分辨率／1080P／720P 和最高 60 FPS。
  60 FPS 使用恒定帧率输出，采集跟不上时会重复帧。当前支持 SDR。
  默认把封存的每段录像在系统桌面另存一份。原件已在桌面时只保存一次，可在设置中关闭副本。

四、录制控制和快捷键
  录制时通过控制条暂停、继续、停止或隐藏控制条。
  Ctrl+Alt+R   开始／停止录制
  Ctrl+Alt+P   暂停／继续
  Ctrl+Alt+H   隐藏／显示控制条
  若快捷键已被占用，可在系统中为本产品入口设置绑定，添加 --toggle 或 --pause 参数。

五、分段保存
  分段默认 2 GB，可改用 MB 或 GB。填 0 则关闭分段。使用 MB 时最小分段大小为 5 MB。
  已封存的分段在异常退出后仍可播放，尚未封存的最后一段下次启动时尝试自动恢复。

六、排障
  银河麒麟／Linux 在终端运行 ./映刻录屏 --check。屏幕采集使用 X11，声音使用 PulseAudio。
  Windows 在程序所在目录运行 映刻录屏.exe --check。详情见同目录的「启动说明.txt」。
  日志位于用户目录中的 .cache/shiying，配置位于 .config/shiying/config.ini。

七、移除
  银河麒麟／Linux 先运行「卸载.sh」移除指向本程序目录的快捷方式，再删除解压目录。
  给所有用户添加的菜单入口可用 sudo ./卸载.sh --system 移除。
  Windows 退出应用后可删除解压目录及为本产品添加的快捷方式。
  录制产物存放在所选保存目录和桌面副本位置。
