拾影录屏 1.1.0-test.2（银河麒麟 V10 轻量录屏工具）
================================================

一、简介
  免安装、不需要管理员权限、不需要联网。界面程序约 0.1 MB，运行时占内存约 20 MB；
  录制引擎为同目录下的 录制引擎/ffmpeg（静态构建，不依赖系统库）。
  支持全屏、多屏任选一块、拖动框选区域、单击选择窗口；可录系统声音、麦克风、两者，或指定一个设备；
  支持暂停／继续、倒计时、指针关／原大／放大、H.264／H.265、MP4／MKV、1080P／720P、按 MB 或 GB 分段。

二、使用
  1. 解压到主目录下任意文件夹（安装包为 deb 时直接双击安装，开始菜单出现“拾影录屏”）（不要解压到 U 盘或 NTFS 分区里直接运行）。
  2. 双击「拾影录屏」打开；或在终端执行 ./拾影录屏 。
  3. 需要开始菜单和桌面图标时，双击或在终端执行 ./安装到菜单.sh 。
  4. 点“开始录制”，录制时屏幕上方出现控制条：暂停／继续、停止、隐藏。
  5. 停止后自动合并保存，默认位置：主目录/视频/录屏/录屏_日期_时间.mp4 。

三、快捷键（全局可用）
  Ctrl+Alt+R  开始／停止录制
  Ctrl+Alt+P  暂停／继续
  Ctrl+Alt+H  隐藏／显示控制条（全屏录制时控制条会被录进画面，可先隐藏）
  框选界面：拖动框选，单击选窗口或整屏，Enter 确认，右键或 Esc 取消。
  若快捷键被其他程序占用，可在“设置 → 快捷键 → 自定义快捷键”中新建，
  命令填写：本目录绝对路径/拾影录屏 --toggle （开始／停止），或 --pause （暂停）。

四、画质与资源占用（1080P 全屏，24 帧）
  流畅：编码最快，录制进程内存约 75 MB，文件较大，适合老机器或 4K 屏。
  标准：默认档，内存约 150 MB，体积与清晰度平衡。
  高清：更清晰，内存约 150 MB，CPU 占用略高。
  4K 屏建议选“1080P”分辨率，可显著降低 CPU 占用。

五、分段、编码与指针
  分段默认 2 GB，可改为 MB 或 GB。填 0 则这次录制不切段。MB 至少填 5。
  到大小后先封存一个可以播放的文件，再继续录下一段。第一段文件名是 录屏_日期_时间.mp4，
  从第二段起是 录屏_日期_时间_002.mp4（三位数字）。
  编码可选 H.264 或 H.265。界面上的编码和格式按钮，以本目录录制引擎实际支持的为准。
  指针选“放大”时，屏幕上出现一块 2 倍跟随窗口，采集把它当成画面的一部分录进去。
  设备一行用左右箭头轮换本机的声音输入。

六、可靠性
  录制过程按 2 秒一段实时写盘。已经封存的文件在程序被强行结束后仍然可以播放。
  尚未封存的最后一段，下次打开会自动恢复为“…_恢复”。

七、常见问题
  1. 打不开、没反应：在终端运行 ./拾影录屏 --check 查看自检结果。
  2. 提示“未签名应用被阻止”：在“安全中心 → 应用控制与保护”中把本程序加入信任。
  3. 没有声音：自检里“声音服务库”需为“通过”；麦克风以系统设置中的默认输入设备为准。
  4. 屏幕采集只支持 X11 会话（麒麟 V10 默认即是），Wayland 会话下无法录制。
  5. 日志：~/.cache/shiying/shiying.log 与 ffmpeg.log；配置：~/.config/shiying/config.ini 。

八、卸载
  执行 ./卸载.sh 移除菜单和桌面图标，再删除本文件夹即可。录好的视频不会被删除。
  Windows 免安装包没有卸载脚本，删掉解压出来的文件夹即可。录好的视频不会被删除。

九、Windows
  免安装包是 拾影录屏_1.1.0-test.2_Windows_免安装.zip。先解压到本机磁盘，再双击 拾影录屏.exe。
  不要在压缩包窗口里直接运行。若出现 SmartScreen，按同目录的 启动说明.txt 操作。
  自检命令是 拾影录屏.exe --check，只检查录制引擎和屏幕采集，不会开始录屏。
