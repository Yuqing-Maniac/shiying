拾影录屏 Windows 启动说明
========================

1. 把整个压缩包解压到本机磁盘的一个文件夹（例如桌面或文档）。不要在压缩包窗口里直接双击 拾影录屏.exe。
2. 解压后的文件夹里应能看到 拾影录屏.exe 和 录制引擎 文件夹。不要把 exe 单独拷走。
3. 双击 拾影录屏.exe。
4. 若 Windows 弹出 SmartScreen（“Windows 已保护你的电脑”），点“更多信息”，再点“仍要运行”。本程序不需要管理员权限。
5. 打不开时，在该文件夹打开命令提示符，执行：
   拾影录屏.exe --check
   窗口会列出录制引擎和屏幕采集是否可用。这一步不会开始录屏。
